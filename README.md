Project 2-
is my second project for Terra Hack Club. It is a text-based casino game built entirely in Python. Players start by depositing money into their account and can choose between two games: a 3x3 slot machine or blackjack. The slot machine features five betting lines (three rows and two diagonals), wild cards, animated spinning reels, and highlighted winning combinations. Players can also use auto-spin for up to 100 spins or place the maximum bet. In blackjack, players compete against a computer-controlled dealer who stands on 17, with options to hit, stand, or double down. A natural blackjack pays 3:2. Both games share the same balance, and a statistics system tracks wins, losses, biggest results, and money earned back.

I created this project to improve my Python programming skills and challenge myself to build something more complex than a basic program. Throughout development, I gained experience with functions, loops, dictionaries, conditional statements, random number generation, and managing data across different parts of a program.

To run the game, download or clone this repository, open the project folder in a terminal, and run python main.py (or python3 main.py depending on your system). Once the game starts, deposit money and use the main menu to choose between slots, blackjack, or viewing your statistics. Follow the prompts to place bets and play. Your balance carries between both games, and the game ends when you quit or run out of money.

Technologies: Python 3, Random Module, Terminal/Command Prompt.
